# Student Performance Analytics

## About
A beginner-level Data Science project that analyses student academic performance using Python.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Features
- Data cleaning and preprocessing
- Statistical analysis
- Student ranking
- Grade classification
- Pass percentage calculation
- Data visualization

## Visualizations
- Subject-wise average marks
- Grade distribution
- Marks distribution
- Gender-wise performance
- Correlation heatmap

## Dataset
Students Performance in Exams dataset from Kaggle.

## How to Run
1. Clone the repository.
2. Install requirements using pip install -r requirements.txt.
3. Open Jupyter Notebook.
4. Run student_analysis.ipynb.
